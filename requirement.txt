CBAM Tool Flow

Step 1 — Upload Excel/CSV
The user uploads the unstructured Excel/CSV file containing the required client data.

↓

Step 2 — Provide & Structure Data
The user is provided with a sample Excel/CSV template that defines the required format. The tool maps and structures the uploaded client data according to this template.

↓

Step 3 — Validate Data
The tool checks the structured data for missing or invalid information. If any required information is missing, the user is notified to provide or update the required data.

↓

Step 4 — CBAM Calculation
Once all required data is available and validated, the tool performs the CBAM calculations using the predefined calculation formulas.

↓

Step 5 — Generate Final Report
After completing the calculations, the tool generates a final report using the provided Word template and displays it to the user for review/download.

Overall Flow:
Upload Excel/CSV → Sample Template → Data Mapping & Structuring → Validation → CBAM Calculation → Final Word Report
